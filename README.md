Katalog Produk🛒

Aplikasi desktop sederhana berbasis JavaFX untuk mengelola katalog produk. Aplikasi ini mengimplementasikan pola arsitektur MVC (Model-View-Controller) dan menyediakan fitur CRUD (Create, Read, Update, Delete) yang interaktif dengan tampilan antarmuka berbasis kartu (card-based layout).

✨ Fitur Utama

Tambah Produk (Create): Menyimpan data produk baru (Nama, Harga, dan Pilihan Foto) ke dalam database.

Lihat Katalog (Read): Menampilkan seluruh daftar produk secara visual menggunakan bentuk kartu yang rapi.

Ubah Data (Update): Tombol Edit pada setiap kartu memungkinkan pengguna memuat ulang data ke dalam form untuk diperbarui.

Hapus Produk (Delete): Tombol Hapus pada setiap kartu untuk menghapus produk dari katalog dan database secara instan.

🛠️ Teknologi yang Digunakan

Bahasa: Java (JDK 17 atau lebih baru disarankan)

GUI Framework: JavaFX (FXML & CSS untuk styling)

Build Tool: Maven (pom.xml)

Database: JDBC (Terhubung dengan MariaDB/MySQL/SQLite sesuai konfigurasi Database.java)
